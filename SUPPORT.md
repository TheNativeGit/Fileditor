# Support & Feedback

**Fileditor** is a free, non-commercial open-source hobby project released under the [MIT License](./LICENSE). There are no paid tiers, subscriptions, or monetization links.

---

## Getting Help & Reporting Issues

If you encounter a bug, have a question about using Fileditor, or want to suggest an improvement:

1. Check the **[README.md](./README.md)** and **[CHANGELOG.md](./CHANGELOG.md)** to see if your question or issue is already covered in the latest release.
2. Browse existing **[GitHub Issues](https://github.com/TheNativeGit/Fileditor/issues)** to avoid duplicates.
3. Open a new **[Bug Report or Feature Request](https://github.com/TheNativeGit/Fileditor/issues/new/choose)** with clear reproduction steps.
   - Diagnostic logs are stored locally on your machine at `%LOCALAPPDATA%\com.fileditor.app\logs\fileditor.log` (never uploaded automatically). Please redact any personal file paths before pasting log excerpts into public issues.

> **Security Vulnerabilities:** Please do **not** report security vulnerabilities in public issues. Follow the instructions in **[SECURITY.md](./SECURITY.md)** instead.

---

## Ways to Contribute (Non-Financial)

- **Star & Share**: Leaving a star on [GitHub](https://github.com/TheNativeGit/Fileditor) or sharing Fileditor with others who work with JSON, XML, Markdown, or ToDo files is always appreciated.
- **Feedback & Ideas**: Thoughtful bug reports and usability suggestions help improve future releases.
- **Website**: Visit [nativeproduction.de](https://nativeproduction.de) for more information about the project.

*Please note: Because Fileditor is maintained as a personal spare-time project, response times on issues and feature requests are best-effort without any guaranteed SLA.*
